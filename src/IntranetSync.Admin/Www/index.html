1. SQL Server（数据库连接）

填写内网 SQL Server，建议使用只读账号，仅授予目标视图 SELECT 权限。


    


    

      
2. View 映射（要同步的视图）

      

        告诉程序从哪张SQL Server 视图读数据、如何按更新时间增量拉取，以及哪些列是内网 PDF 链接。
        若不需要唯一键：唯一标识列留空，填好增量列（如 updated_at），则水位之后查出的记录会全部推送。
      

      

        
        
        
        
        
      

    


    

      
3. 云端 API（行数据 POST 同步）

      

        填写完整的 POST 接口地址，程序会直接对该地址发起请求。
      

      

        
        
        
      

    


    

      
4. OSS（PDF 对象存储，与云 API 分开配置）

      

        仅处理 PDF 文件上传。推荐 STS：填写下方「STS 接口地址」，或留空由程序根据第 3 节地址尝试推导。

只影响内网 PDF 的下载与上传 OSS；与「多久同步一次」无关。
